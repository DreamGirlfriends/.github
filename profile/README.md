**Approach**

These platforms emphasize creation. You select or generate looks, define personality elements, and optionally set a voice style. The resulting companion lives in one conversation thread you can reopen. Free access is typically brief. Full customization, image generation, and voice tend to sit on paid plans.

**Steps**

- Open the creation tool.  
- Choose or generate appearance.  
- Set personality and background notes.  
- Begin chatting.  
- Return to the same thread later.  
- Upgrade for extended features.
